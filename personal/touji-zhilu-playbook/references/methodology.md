## 1. 自我定位

## 2. 总仓位与风险框架

- **现金为王是常态仓位。** 2025-11 现金占身价 89%（#125），2026-06 仍是 85%（#238）。留天量现金是为了等下一次"一切都打大折"（#182 #210 #238）。
- **"赢不赢不重要，不输很重要。"** 输了就吃利息过日子，全球金融市场几年一次大姨妈，总会等到下次上车。#115
- **一切仓位用「占身价百分比」计量并公开**，方便别人判断轻重：0.7%（#122）、0.2%（#129）、0.5%（#131）；说过若 BTC 一周内闪崩到 77k 会直接梭 5% 身价（#129）。他明确说这样更透明、方便抄作业。#125
- **心疼阈值 ≈ 10 万美元**：单笔主观交易亏超这个数就心疼。用现实物价给自己套缰绳——亏 10 万 = 亏一块金劳，赚 50 万 = 赚一辆兰博——"大脑不允许我做太危险的交易"。#254
- 赚更多的边际吸引力已经很低（人生财务目标 2025 年末就达成），而亏损很心疼 → 风险偏好持续下调。#254
- 认为自己"人生基本没回撤"是这套结构的结果，代价是**会完整错过一些大行情**（如 2026 上半年半导体行情，#238），并且他接受这个代价。

## 3. 择时与出手纪律

- **抄底只买急跌。** 缓慢阴跌的钝刀子不出手，要看到 BTC 几分钟内跌 3-5% 这种大规模清算再动手。蹲不到就不买。#239
- **耐心是主动策略**，不是没机会：手握现金不急着抄底，只等自己想要的折扣。#109
- **用群众情绪切换模式**：市场开始喊"VC 和项目方都不赚钱了""要完蛋了"、参与者卖儿卖女时 → 切"仅做多模式"，专注买便宜货；市场开始喊"人类文明进入新的伟大进程""年末 100 万刀""meme 是信息时代最伟大的发明"时 → 切"只卖出 + 无风险套利模式"。#25
- **不预测顶部价格**，靠场内外指标报警：Coinbase App 排名、meme 币资费、交易所借 U 利率、Google Trend、链上交易 bot 手续费、链上 gas。#59
- **全球资产贵贱的标尺**：iShares 新兴市场指数 EEM——相当于全球股市的"山寨币指数"，历史红区（2007/2018/2021 及 2026 初）是危险区，绿区是价值区。留现金就是等 EEM 进绿区时全球扫货，做好等 2-4 年的准备。#210
- **不追已经涨了 X 倍的资产**，哪怕叙事是对的。承认 AI 是第四次工业革命，但估值不实惠就不买；宁可等媒体开始报道"X 优质资产跌幅超 XX%，几年前买入的人利润全部回吐"这类标题时再打现金子弹。#209 #134
- 节奏比喻：**熊市当秃鹫等尸体，牛市当鳄鱼伏击机会，平时吃利息。**#166 熊市是喊梦想和价位的时候，牛市是把现金从接盘侠口袋里掏出来的时候。#201
- 最容易复刻的"圣杯"：**当钓鱼佬蹲机会**——平时小仓位玩玩保持盘感，大机会出现时猛干。#138

## 4. 做空纪律

- **看空但不做空。** 大仓位做空是愚蠢的，持有现金吃利息更舒服。#118
- **没有 edge 的做空是世界上很危险很愚蠢的事**——这句是他自己反复说的。#224
- 做空庄币（PIPPIN 案例，#215 #224）——他复盘赢下来的三个要点：
  1. **仓位小**（13 万 U），且**主动劝阻别人跟单**：越多人跟着做空 = 给庄送燃料 = 风险越高；
  2. 自身**影响力**足以让庄操盘有忌惮；
  3. **运气好**。
  论点来自"perp dex 在 LP 可能受损时有中心化权限拉闸"（Lighter 干掉 ARC、Hyperliquid 干掉 JELLYJELLY 的先例），庄在 Aster 上操盘是因为币安打击多账户操纵而 Aster 不管却搬运币安流动性。资费转负后平仓。他把这类机会定性为"几个月才逮一次"，且明确写"请勿模仿"。
- 反例记录在案：**做空 SpaceX 认亏 6 万多**（#240 建仓 → #241 平仓），认输理由是标的一小时无新闻跳涨 15%，证明"软柿子"判断错误；观点没变但承认时间窗口选错。

## 5. 杠杆

- **杠杆只用来放大确定性高的机会（套利类），持仓最多几小时**，不用于赌方向。#139
- 早期三次真梭哈，共同点都是"用杠杆放大高确定性事件"：
  - 2021 年程序自动狙击马斯克提及 DOGE 的推文，用 2 主账户 + 20 子账户绕开单账户持仓限额；

## 6. 套利与"市场摩擦"利润（主要现金牛）

- **交易所间价差**：大户爆仓时 OKX 合约相对币安溢价 8%+（RAVE，出现 3-4 次）；暴跌时现货相对合约负溢价 -5%，几小时后翻正溢价 +10%（ARIA）。用 vibe coding 随手写程序去套。#227
- **现货多 + 合约空的双向吃法**（RAVE，#228 #234）：庄弃盘 → 合约溢价 → 吃资费；庄继续发力 → 现货溢价 → 吃 spread。两头都不亏。唯一风险是庄几分钟砸 50%+ 导致交易所 ADL 掉合约腿，所以另写了**监控 ADL 队列 + 自动减仓**的程序。同样打法也可用于其他庄币，但仓位不能开太大。#231
- **成本要算进去**：一次两天付出 3 万 U 资金费成本（#229）；平早了也照实说（#230）。
- **空投刷量**（Aster 全过程，#77 #78 #80 #81 #82 #87 #88 #106）：计划烧 70 万美元手续费，一号一 IP、上百个号对刷规避女巫；预期拿到 140 万美元空投的情况下对冲 40 万（没全对冲，因为存在拿不到币和币价暴涨两种风险）；规则改动后紧急停机；最终投入 94 万美元、官方补分配后获利 23 万美元。
  - **投入额的定标准是"100% 亏光也没事"**——任何刷量的人都该有全损的心理觉悟，别盲目 FOMO。#80
  - **时间成本要计入**：账面赚钱，但投入的大量时间和机会成本在牛市里太贵，"算时间成本的话我也被反撸了"。#88
- **零和博弈的船人多了会沉**：2021-2023 中期 MEXC 这类自营做市所几乎没有风控，任何套利策略都能框框赚；套利者和 toxic flow 多了 → 上风控 → 2023 年末对套利类账户直接没收。#57
- **薅平台羊毛也认真做**：4 个 Bybit 账户各办卡、VIP5 返 8%、每月上限 400U，合计月薅约 1600 刀（#62）；发现 Bitget 卡月限额 30 万 U、最高等级可到 300 万美元/月，定位是"买房买车"级别（#112）；币安单号额度从 1 万 U 提到 5 万 U 时把 120 个号全塞满（#61）。
- 认可 Plasma/Hyperliquid 式"资本主义分配"，反感项目方搞平均主义分配——因为大户照样用买 KYC 多号绕过，只是更麻烦。#79

## 7. 微观结构 / 订单簿

- **做市商在跑"跟随知情交易者"策略**：监测到币安现货或合约出现大单把价格拉超约 3%、且 bid1 还挂着大额买单时，他们会跟着买入一部分并大幅调薄订单簿——结果是你下 3% 滑点的单最终能把价格推 6%+。#14 实测在 BR 上用 2% 滑点买入把价格驱动上涨 11%。#18
- 在**高 OI 的小市值山寨币**上用高滑点买入容易触发这类跟庄策略。这就是很多鲸鱼"明明没买多少价格就涨很多"的真相——**差价被做市商吃了**。#19 #127
- **反向利用（退出时）**：先在当前价上方 0.3-0.4% 挂 limit 卖单，再去 bid1 挂一个超大额买单，把预测型 MM 吓一跳去抬价，正好 hit 掉你挂的 limit。#126
- **跨所时序**：币安 API 在东京延迟最低（1-2ms），做市商可能在别的所有低延迟通道和跨洋微波线路。所以进出都要先在其他交易所下单、5 毫秒后再打币安，等 5-10 秒订单簿恢复正常再做反向操作。#14
- **不敬畏市场**：市场是人设计的系统，人设计的系统就有漏洞，市场先生隔三差五失灵一次，创造不对等机会。他把自己定位为"抓市场先生漏洞的人"。#98

## 8. 持仓与退出

- **不要因为"觉得涨太多了"就从一笔好交易里退出**，要用长周期趋势指标退出（Supertrend 4h/8h/12h）。他统计自己买到底部的小市值 meme 大多只翻倍就跑了。#21
- **必须设"论点不成立"的止损**：#125 的复盘——Supertrend 在 96k 是支撑，那么跌到 92k 时论点就不成立，应该退出，而当时他没设。这是他自己给自己记的最大问题。
- **确定性不强的交易不格局**：赚个超跌反弹的钱就走。#102 #103
- 愿意长期拿的仓位有两个共同点：**建仓成本在绝对底部**（所以有耐心）、**已有厚浮盈**（跌 30% 也不伤本金）。#105
- **持仓要有明确保底价值**：市场环境差时更愿意拿 10m FDV 的合约 meme 组合（有明确底），而不是大币（没有明确的底）。#102 #101 撒糖豆策略：100 万美元分散到 10 个币，且不公开是哪些（怕影响价格、怕庄看到不拉盘）。

## 9. 非加密资产配置

- **股票账户的定位是长期投资**，买了几年不管；不做需要盘感和胆识的短炒——"除非我能在这个游戏里作弊，否则就老老实实玩凡人的游戏（捕获长期价值）"。#43
- 只投能力圈内：芒格那条"在能力圈之外投资等于赌博"被他用来拒绝一切圈外实业和生意。#64

## 10. 防御与生存（他自己最看重的一块）

- 认为芒格/巴菲特给普通人最大的价值是**《人生的防御之道》**：只投能力圈；"我只想知道我会在哪里死去，这样就永远不去那里"；人通过模仿学习，所以选择模仿对象极其重要。#64
- **币圈的四种死法**（他刻意研究失败案例来绕开）：① 开杠杆被爆；② 内部或外部原因导致资金被盗；③ 存资金的交易所/项目爆雷；④ 后期自认天下无敌然后 All In 一个大烂摊子。#64 补充第五种：**人身侵害**。#66
- **人身安全**：不分享行踪、不参加线下会议；住的社区都是同等或更有钱的人（另一种"大隐隐于市"）；去大商圈可以穿戴，但半夜去苍蝇馆子就穿优衣库——**不做所在地最扎眼的那个**；绑架案多为熟人作案，所以不和乱七八糟的人搞熟去线下见面。#66
- **账号与密钥**：用 1Password 而非浏览器自带密码管理器（后者中个小恶意程序就全破）；**交易所登录密码不进任何密码管理器**；2FA 验证器只放在 iPhone 上；像爱护助记词一样爱护恢复密钥。#63
- **浏览器插件**：沉浸式翻译这类会读写页面的插件要限制到"点击时才授权"，且**不要在有钱包或已登录交易所的浏览器里用**——对套利客是利器，对黑客是超高价值目标。#8
- **API 权限**：DEX perp 无法创建只读 API，可写 API 一旦泄漏就等于账户资金可被对敲盗走且黑客逍遥法外（引 2022 年 3commas 后台被入侵导致币安 API key 被盗、黑客用小币对敲的先例）。所以在这类所放着 1000 万 U 也只敢手动登录看收益，不敢建 API 自动统计。绑定 IP 也不够。#110
- **大额转账前先小额测试**：把上百万 USDE 从币安走了一个 Bybit 尚不支持的 EVM 网络转过去，联系客服操作 15 天才拿回。他有核对地址的习惯，但当时没有"先小额试转"的习惯。#154
- **定时提现的习惯救过他**：LBANK 2024 年因某账户赚太多而冻结，因为常提现，被封时账户里只剩 2 万 U。#247
- **熊市排雷**：从各种小交易所、理财协议提币，USDE 这类大部分换成 USDT 或 USD1——"你永远不知道熊市里埋着多少雷"。#185
- **身份与账户基建**：各国签证、ID、驾照、银行账户在能力范围内办得越多越好。#67 台海推演用俄乌当前车之鉴——战争后俄罗斯人以**本国居民身份**开的海外银行券商账户被关户/清退/要 AML 材料，而以**海外居民身份**开的原有账户基本还能用，只是不给新开；所以要趁和平年份提前把架构和身份做好。#133

## 11. 影响力作为资产

- **在加密市场，影响力 = 金钱和权力。** 自己有大资金 + 强影响力 → 想让什么涨就让什么涨；这既爽，对自己的交易也是 +EV，因为总能买到相对底部。#22 #23
- 类比：二级市场喊单带货 ≈ 跨境电商开抖音直播——同样的货，加一条流量渠道就能大幅提升销量和利润。多数人不做是因为害羞、做不出内容、怕被骂，机构则怕政治风险。#26

## 12. 商业与人生方法论

- **轻资产套利式创业**（无人机表演出海为例，#147）：假设只有 100 万美元，绝不自己买设备、跑许可、投流做成重资产生意；而是找已经成熟的团队建立**代理商关系**，把他们当作一个下属模块，包装成自己的细分定制产品（如把无人机表演 + 婚庆结合成"富豪求婚产品"），运营好社交媒体然后直接执行——**失败只损失时间成本，可以立刻切换到下一个点子**。"人穷的时候脑子就更要活"，付出便宜的时间成本去搏暴击收益，不要在一个点子上重资产梭哈。
- **试错的分水岭**：代价只是时间、精力或面子 → 大胆试，不用听任何人说 No；代价是钱、人脉、身体健康这类不可再生稀缺资源 → 慎重再慎重，只投极少资源。#153
- **资产 <10 万美元的人**最好的路径是真实世界的商业套利、细分领域套利、肯付出时间的领域套利，**而不是来合约订单簿和他这种人 PVP**。#149
- **时光机策略**：把 A 地做成的事照抄到 B 地本土化执行；他认为跨国信息差会长期存在。#54
- **保持商机笔记的习惯**：生活中看到商机就记下来，并在脑子里回测"如果我一穷二白白手起家，我会怎么做好它"。#147
- **AI 用法**：书籍无用论——不必大费周章读完一本书，想办法让 AI 读完提炼信息，效率高太多 #10；后期直接用 Claude Code 和 Codex 做公司全自动化审计和资费套利程序，因为用得多了反而发现业务大量可优化之处 #227；改游戏存档二进制的实测里 Claude Opus 4.6 一次做对而另一模型多次改坏 #211。
- **向内归因，不酸别人**：拆解"我为什么不如同龄的 Alon"时归因到自己的取舍、懒惰、天赋和选择，结论是"我无法改变今天，但可以为下次机会做准备"#69；看到比自己强的人只学不踩 #68；对造谣他"代持/白手套/前台代理人"的旧熟人，回应是**"你可以眼红，但你得学会把眼红当作动力"**——有实力者必有可学之处 #144。
- **差距的三个来源**（#146 #145）：① 认知差 + 执行力，决定同一个机会出现时你能否把握；② **代差**——对方早你一个周期完成基建和原始资本积累、已建立护城河；③ 天时——"在现在这种市场环境扑腾 5 年，不如提前准备好基建然后在 2024.11 那种狂暴牛市里疯狂努力一个月"。
- **熊市该干的事**（#146）：打磨 edge（基建 / 编程 / 社交 / AI 使用能力 / 体验新产品）；多找细分领域机会，找寡头还没垄断的行业（他点名预测市场和 perp dex）；不局限于 crypto，多开券商和银行账户当作"人生基建"。
- **消费观**：自住房是不创造现金流的负资产，买房 = 锁定流动性 = 潜在高额机会成本；买房只花了身价 3%，买车计划只花 1%。#138
- **生活的优先级**：意识到"美好青春年华"是不可增值资产且只剩几年，所以主动分配时间去打游戏、旅游、好好生活。#227 #138
- 关于低调：过了一段完全没有分享欲的日子后，理解了"只有低调性格的人才能赚着美元在中国生活"——不炫耀、不惹事、不提高社会治理成本，日子就很好过。#237

## 13. 结构性 / 行业观点（长期，仍需按日期看）

- **Hyperliquid**（2026-02，#175 #176）：认为是唯一能跑出来的 perp dex，币安也视其为最重要竞争对手。核心论据不是技术而是**监管地理**——Cloudflare Radar 数据显示 HL 前端用户大量来自美、欧、日这些"禁止地区"，而这些用户是合规背景下 CEX 永远不敢碰的雷池（美国国籍是 CEX 绝对红线；日英朋友要靠泰国驾照、帕劳 ID 保号）。加上先发优势和 perp dex 全靠交易员口口相传的推广特性。反过来，离岸用户（如中国人）已经能用币安/OKX/Bybit，没动力去别的 perp dex。
- **加密的人口红利**（#180 #146）：欧美日韩台的 85/95 后投资过加密货币的比例极高，购买力还在增强；他们平时不买，但一定会在下一次投机狂热时参与。"杯子在变大，只需等水来"——只要耐心等几年，必然会有某个宏观事件（金融危机导致的大规模央行印钞 / 银行替代叙事 / 黄金替代叙事）驱动下一轮牛市。
- **中国不会合法化 crypto**（2026-01，#156）：地缘政治决定的——中国视 crypto 为"金融翻墙工具"、美方最锋利的金融之刃，打压只会更严；他预判未来 1-2 年可能出"出入金 = 非法换汇 = 入刑"这类新规。
- **山寨币市场的分配结构**（#39）：直观展示了没有财富再分配的社会会怎样——基本盘被割完，热钱进入既得利益者口袋后被用于理财和买 BTC/美股，流通于"民"的购买力减少，财富效应削弱，最终既得利益者赚钱能力也大幅下降。他的结论是"何以解忧？唯有下次大放水；何时大放水？唯有遇到大危机"。
- **最好的买点**是 MicroStrategy / BitMine 这类杠杆囤币方被清算的时刻，但（2025-11 时点）他认为一年内看不到。#124
- **牛市顶的风险来自习惯**（#184）：承认在"一切优质资产的超级周期"里（法币持续贬值 + 生产力科技飞速进步），把眼光放到 5-10 年现在什么都便宜；但如果人们养成无脑 buy the dip 且次次都赢 → 养成加杠杆放大的习惯，那么再优质的资产也总有一部分杠杆玩家要买单结账。
- **币安上币策略的变化**（2025-11，#121）：曾有一段全力扶持 BSC 系的时期——只要能贡献筹码且是 BSC 系就上，Base/Solana 系不可能上，"让牛市只能发生在 BSC 上"，市场上大批 BSC 垃圾都是那时的产物；后来开始修正（上 MET、Alpha 上 Solana 的 PLAY）。
- **发币方 vs 交易方**（#155）：做交易赚的是现金，但赚钱速度永远跟不上"印筹码的人"（资产发行方）。如果发币不违法他一定会发币或收购扶持小项目——但他选择保住能正常出入中国的身份，信条是"爬得很高且不得罪中国或美国任何一方，这辈子平平安安落地"。
