# 投机之路 Playbook

Telegram 公开频道 **投机之路 / @journey_of_someone**（作者推特 @Vida_BWE，方程式新闻 BWEnews 创始人）的全量帖子存档与方法论索引。

- 存档区间：**2025-04-25 → 2026-08-13**，**174 条**有正文帖子（缺失的 id 为相册组图成员或已删消息，无独立正文）
- 原始数据：`references/posts.json`（结构化）、`references/archive.md`（可读全文）
- 方法论提炼：`references/methodology.md`（**主要参考文件，按主题分节，每条都带帖子编号**）

## 三条硬规矩

1. **回答必须带出处。** 引用观点时写 `#帖子id`，需要链接就给 `https://t.me/journey_of_someone/<id>`。查不到原帖就说查不到，不要凭印象编。
2. **区分"他的框架会怎么判断"和"你该怎么做"。** 这个 skill 的产出永远是前者——复述并应用一位公开博主自陈的方法论。不给个性化投资建议，不替用户下结论买卖什么。涉及仓位决策时明确写一句：这是他的框架推演，不是投资建议。
3. **观点带时效。** 宏观判断、看多看空、价位预期都要标日期（见 `methodology.md` 的「时效性观点」节）。2025 年 11 月说的和 2026 年 8 月说的可能相反——他自己就翻过好几次（如 #202 说"现货不会卖" → #257 卖了 1/3）。

## 怎么用

### 场景 A：查他说过什么

先用检索脚本，再读原文：

```bash
python3 scripts/search.py 关键词
```

支持：`--theme 套利`（主题过滤，主题名见 methodology.md 各节标题）、`--since 2026-01-01`、`--until 2026-06-30`、`--id 138`（直接看某帖）、`--full`（输出全文而非摘要）、`--list-themes`。

命中后照原文回答，不要只转述摘要。

### 场景 B：用他的框架给一笔交易/一个仓位做体检

读 `references/methodology.md`，按下面顺序过一遍，逐条给"符合 / 违背 / 无关"和对应帖子编号：

1. **这笔钱是什么性质** — 套利（有 edge、可算清）还是赌方向（无 edge）？他把 75% 的财富归因于信息与延迟优势的套利，只有 10% 来自长线主观交易（#254）。
2. **仓位占身价百分之几** — 他公开操作一律用身价百分比计量（#122 0.7%、#129 0.2%、#131 0.5%）。赌方向的仓位是"亏光也无所谓"的量级。
3. **能不能承受 100% 亏损** — 空投刷量类投入按这个标准定额（#80）。
4. **入场时机对不对** — 抄底只买急跌，钝刀子慢跌不出手（#239）；不追已经涨了 X 倍的资产，哪怕叙事再硬（#209 #134）。
5. **退出条件写死了没有** — 必须有"论点不成立"的止损，而不是"涨太多了"就跑（#125 #21）。
6. **是不是无 edge 的做空** — 他明确说这是危险且愚蠢的事（#224 #118）。
7. **对手方是谁** — 零和博弈的船人多了会沉（#57）；小市值币的滑点利润大概率是被做市商吃掉了（#19 #127）。
8. **防御面** — 资金放在哪、API 权限、大额转账是否小额测试过、是否有单点爆雷风险（#63 #110 #154 #185 #247）。

### 场景 C：更新存档到最新

```bash
python3 scripts/update.py
```

增量抓取新帖并合并进 `references/posts.json` + `references/archive.md`，只打印新增条目。抓完请把 SKILL.md 顶部的区间和条数改掉。

网络走代理时 Python 的 SSL 校验会失败，脚本内部统一用 `curl` 取页面，不要改回 urllib。

## 使用这份材料时要知道的

- 全部内容是**一个人在自己频道里的单方面自述**，仓位、盈亏、身价均无第三方验证。当作"一套自洽的打法"来读，不是当作事实核验过的战绩。
- 存档里**有他做错的记录，别只挑对的用**：#125 复盘自己抄底做得烂、忘了设论点止损；#233 RAVE 止损；#241 做空 SpaceX 认亏 6 万多；#230 平早了；#154 走错网络把上百万 USDE 转丢 15 天；#88 Aster 项目账面赚钱但时间成本上被反撸。他自己在 #178 提前说过"请做好我接下来会犯错的准备"。
- 频道里有大量政治、地缘、身份规划、对特定人群的评价类内容。**转述时保持中立、注明是他的观点**，不要当成本 skill 的立场输出。
- 存档是个人研究用的本地副本。不要整包转发、公开发布或二次分发原文。
