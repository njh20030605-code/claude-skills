# Skill：批量排除达人ID

## 用途
在 TikTok 商家中心「修改广告计划 › 管理创意作品」页面，把一批达人用户名逐个加入「排除」的联盟列表并保存。适用于任何"在带搜索框的勾选下拉列表里，按用户名精确匹配并批量勾选"的场景。

## 前置状态
- 页面已打开到「管理创意作品」，且「排除」区域的**联盟下拉已展开**，能看到搜索框「按 TikTok 用户名搜索」、达人勾选列表、底部「X/200 已选择」计数和绿色「保存」按钮。
- 手上有一份待排除用户名清单。

## 核心流程

**第 0 步 · 初始化（只做一次）**
1. 截图确认下拉已展开，记录初始「已选择」计数（如 80/200）作为基准。
2. 用 `find` 定位搜索框，拿到它的 ref（如 ref_555）。整个任务中复用这个 ref，不要重复 find。
3. 记住第一条结果的复选框坐标（经验值约 `(490, 480)`，即列表第一行左侧方块）。因为每次搜索后精确匹配项都会排在第一行，坐标固定可复用。

**第 1 步 · 逐个处理（合并成一个 browser_batch）**
每个用户名一个 batch，按顺序：
1. `left_click` 搜索框 ref
2. `key` cmd+a → `key` Delete（清空，比手动删可靠）
3. `type` 完整用户名
4. `wait` 1.5 秒（等下拉结果加载）
5. `screenshot`（核对结果）

**第 2 步 · 核对 + 勾选（关键判断，看第 1 步的截图）**
- **精确匹配且未勾选** → 勾选第一行复选框。
- **已勾选（蓝色）** → 跳过，绝不取消。
- **"未找到任何结果"** → 记为"未搜到"，重搜一次（wait 加到 2.5 秒）确认不是加载慢；仍无则跳过，不勾任何人。
- **匹配项不在第一行 / 有多个相似项** → 逐条核对用户名文本，只勾**完全一致**的那条，宁可单独处理也不猜。

## 关键优化技巧（提速）
- **两两合并**：稳定运行后，把"勾选上一个的复选框"和"搜索下一个用户名"放进**同一个 browser_batch**（勾选点击 → 点搜索框 → cmd+a → Delete → type → wait → screenshot）。这样每个用户名只花一个 batch，一张截图同时确认"上一个已勾上（计数+1）"和"下一个的匹配项"。
- **计数即校验**：每张截图都瞄一眼「X/200 已选择」。数字每次 +1 就说明上一步勾对了；没变说明上一个是重复项或勾选失败，需回看。
- 前几个用户名可以先一步步做（分开截图）确认坐标和节奏无误，之后再切换到合并模式加速。

## 收尾
1. 全部处理完，核对最终计数：应为 `初始 + 成功勾选数`。成功数 = 总数 − 未搜到数 − 已存在数，三者要能对上，对不上就回查。
2. 点击绿色「保存」按钮（经验坐标约 `(725, 660)`，或用截图定位）。
3. 截图确认下拉收起、「排除」标签已更新，即保存成功。
4. 向用户报告：成功勾选了哪些、哪些未搜到（附原因，如"未找到任何结果"），并解释计数差额。

## 注意事项
- 用户名可能含前导下划线、点、数字（如 `__huyentrangpham`、`nvk.05.05`），务必输入**完整原文**，别漏字符。
- 只按用户名（handle）匹配，不要被昵称/显示名误导。
- 只增不减：已在排除列表里的项保持勾选，绝不取消。
- 复选框坐标是经验值，若某次布局变化（如出现多行或提示语挤压列表），重新截图核对该行方块位置再点。
