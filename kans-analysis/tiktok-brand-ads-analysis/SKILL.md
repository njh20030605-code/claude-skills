# TikTok 品牌广告分析模型(越南市场 C-ads)

## 核心原则

C-ads 重「种草 / Consideration 人群积累」，**不是即时转化工具**。
因此**不要只用 GMV / ROAS 判断成败**，核心要看：

- **CPCo**(种草人群获取成本)的变化趋势
- **Co 人群规模**的增长情况

只有在确认了 CPCo 与 Co 人群变化后，才把 GMV / ROAS 作为辅助参考。

---

## 零、行业 Benchmark(每次数据分析必须对标)

来源:平台《出海商家 Consideration Ads 投放 Playbook》Y26Q3 对外版。货币按 USD 理解。

| 行业 | CPCo | 互动率 | 互动成本 | 点赞成本 | 评论成本 |
|---|---|---|---|---|---|
| Beauty and Care | 0.03 | 1.4% | 0.03 | 0.1 | 28.7 |

**强制要求**:只要用户给了数据,输出里必须有一张「实际 vs 行业 Benchmark」对比表:
- 逐项列出:指标 / 实际值 / Benchmark / 差值或倍数 / 判断(优于 ✅ / 持平 ➖ / 劣于 ⚠️)。成本类越低越好,互动率越高越好。
- 实际数据缺某项指标(如没有点赞数、评论数)→ 该行写「数据缺失」,并列入缺失项清单,不要跳过。
- 币种不是 USD 时先换算再对比,并写明汇率(USD × 6.8 = RMB;₫3,860 ≈ ¥1,即 1 USD ≈ ₫26,248)。
- 素材级分析时,每条素材也按此 Benchmark 打标,用于汰换判断(高互动、低种草成本的加码)。
- 结论中注明这是平台全市场样本均值,不是越南单市场口径。

## 一、先确认基础信息(数据缺失必须明确指出)

逐项确认下列信息；任何一项缺失，先列出「缺失项清单」，再在已知数据范围内给结论：

1. 投放市场(应为越南)
2. 产品行业(快消 / 耐消)
3. 是否大促场景
4. 投放周期
5. 总预算与 C-ads 占比
6. 当前出价方式(应为 **NoBid**)

---

## 二、四个基操维度逐项诊断

### 1. 预算规模
- 单个 Ad Group 预算是否超过 **$85K 临界点**?(超过需拆分)
- 是否低于 **$100** 导致数据无参考性?
- 是否偏低、有提升空间?

### 2. 定向
- 是否过窄?(L3/L4 兴趣、自定义人群、叠加过多条件)→ 会导致 CPCo 上升、漏斗受限
- 评估是否需要放宽定向。

### 3. 预算与排期
- 是否使用 **Lifetime Budget**?
- 投放时长是否够长?(延长时长可降本:**1→7 天约 -6%、1→14 天约 -8%**)
- 是否误用 **dayparting**?(会抬高 CPCo)
- 是否在做 **Always On** 持续积累?

### 4. 创意数量
- 每个 Ad Group 创意数是否落在 **6–10 条高效区间**?
- 参考:**1→5 条 CPCo 降约 $0.04**;超过 10 条边际效益不明显。

---

## 三、大促场景额外检查(仅大促时)

- 是否提前 **≥7 天蓄水**?
- 品牌预算占 TTL 是否 **>15%**?
- 是否按三阶段节奏:
  - **预热 T-15**:低成本种草，约 **20%** 预算
  - **蓄水 T-7**:扩量，约 **50%** 预算
  - **爆发 Peak Day**:种收一体,约 **30%** 预算
- 达人结构:头腰 / 腰尾占比是否合理?
- 素材加热门槛是否达标:发布前 3 日 **VV > 1000**、**6s VTR > 34%** 或 **互动率 ≥ 3%**。

---

## 四、效果验证维度(评估真实效果，而非单看 GMV)

- **CPCo 趋势**(是否随时长 / 创意 / 定向调整而下降)
- **Co 人群规模增长**
- 八大人群从 **Consideration 向转化层的流转率**
- **新客贡献占比**
- **对 GMAX 的联动增效**(召回率、GMAX CVR 是否随 C-ads 提升,见第六节)

---

## 五、输出结构

固定按以下三段式输出，并给出可执行的下一步动作:

1. **现状诊断** — 基础信息 + 「实际 vs 行业 Benchmark」对比表(第零节,必出) + 四维度(+大促维度)的事实判断
2. **问题定位** — 指出导致 CPCo 偏高 / Co 增长受限的具体原因
3. **优化建议** — 可执行动作清单(明确改什么、改成多少、预期影响)

> 提示:每条建议尽量绑定一个可量化目标或预期方向(如「定向放宽预计 CPCo 下降」),便于复盘验证。

## 六、平台官方 Playbook 补充(《出海商家 Consideration Ads 投放 Playbook》Y26Q3 对外版)

来源:平台对外分享的飞书文档,基于 209 个出海商家样本。
**口径提醒**:为平台全市场样本均值,非越南单市场、非 KANS 自有数据;引用时标注「平台样本」,与自家 CPCo 对标前先确认口径。
行业成本基准已录入第零节;标签体系等其余配图未录入,需要时回原文看图。

### 1. 增效逻辑:C-ads × GMAX
- C-ads 不只种草,可提升 View Content / 加购 / 发起结账等前链路指标,同时带动 **GMAX 召回率与 GMAX CVR**。
- 行业分工:CE / Lifestyle(高客单、决策链长)→ 做决策前教育;**FMCG / 美妆 / 服饰 → 持续提升购买效率与转化稳定性**(KANS 属后者)。
- 增效需同时满足四项:**素材够好、预算充足、人群够准、周期够长**。种草端看素材指标 / C-ads 预算绝对值 / 人群精准度;转化端看投放时长 / 品效配比 / 绝对值。

### 2. 素材(补充第二节第4点)
- **优先达人素材**:经 GMAX 二次触达后,CVR 约为 Inhouse 自制素材的 **2.3 倍**;达人素材互动率与 6s VTR 越高,种草与拉新效率越高。
- 内容贴行业决策点:美妆→使用前后对比、真实效果、用户反馈(增强功效可信度);3C→场景实测与核心卖点。
- 投中汰换:小预算测试 → 预算集中到高互动、低种草成本素材(行业成本基准见第零节)。

### 3. 人群
- **至少提前 15 天**蓄水种草,高峰期再召回高意向人群(与第三节预热 T-15 一致,可作为其平台依据)。
- 标签不止泛兴趣:可圈搜索过 / 加购过 / 购买过 / 互动过的高意向用户。
- 常用两类:**类目 + 行为 + 卖点关键词**组合人群;**功效卖点标签**(淡斑、补水、控油、防晒等,FMCG 行业已上线)。

### 4. 新品 / 爆品投放价值
- 新品冷启:品牌人群破圈,触达 **+46.3%**,GMAX 召回率 **+4.6%**。
- 爆品 / 大促:品牌背书强化决策,拉升加购与结账,**GMAX CVR +6.5%**。
- 新品节奏差异:手机 / 家电 = 前期重品牌破圈 → 中段收敛做效率与人群校准 → Peak day 当周集中放量用效果承接;**FMCG / 服饰 = 前期效果稳定铺量预热 → Peak day 当周快速抬升品牌占比并在 Peak day 引爆 → 节点后再营销承接长尾**。

### 使用方式
诊断 FMCG / 美妆账户时,在「优化建议」中可引用本节作为方向依据(如:素材是否以达人为主、是否提前 15 天蓄水、是否用了功效标签人群、大促周品牌占比是否抬升),并标注为平台样本结论。
