# 分析框架

`metrics.py` 的输出顺序就是这份框架的顺序。照着走，不要跳步——尤其不要在没给大盘定调前就说某个品牌"涨得好"。

## 五步

### 第 1 步 · 大盘定调（一句话）

`总 GMV 口径环比 X%` + 这是大促周还是自然周 + 入榜门槛变化。

这句话是后面所有判断的地基。缺了它，"+104%" 会被误读成运营成果。

### 第 2 步 · 增量来源（一张表）

五个渠道的环比 + 占比位移，按环比排序。找出：
- 唯一/明显跑赢大盘的渠道 → 这是本周的**增量承接渠道**
- 明显跑输大盘的渠道 → 这是本周的**份额流失渠道**

典型结论句式：「增量集中在 X 渠道（环比 +A%、占比 +B pp），Y 渠道跑输大盘 C pp」。

### 第 3 步 · KANS 定位（两句话）

1. 总 GMV、环比、跑赢/跑输大盘多少 pp、排名变化
2. 五渠道逐个对标大盘同渠道，找出跑赢最多和跑输的

跑输的渠道**必须**走 pitfalls #5 的加权 vs 中位数校验，再决定要不要写成短板。

同时看：占比位移方向（是否被稀释，pitfalls #6）、AOV 与推算单量（增长来自量还是价）。

### 第 4 步 · 竞争格局（三类打法）

把异动品牌归成三类，每类一句话 + 代表品牌 + 关键数字：

| 类型 | 特征 | 意味着什么 |
|---|---|---|
| **跟随型** | 和大盘同向，加码同一个增量渠道 | 这是行业共同动作，不构成差异化 |
| **逆势型** | 反向操作但总量保住 | 最值得深挖——它找到了成本更优的结构 |
| **空降型** | 单周 +200% 以上冲入头部 | 通常是国际大牌大促排期，改变了竞价对手构成 |

顺带回答两个问题：
- 中国品牌梯队里我们排第几，和第一名差几倍
- 结构上离我们最近的对手是谁（找五渠道占比最接近的），差异集中在哪个渠道

### 第 5 步 · 下周动作（三条，都要可执行）

一条打口径（提前说明下周大概率回落），一条验证本周主力渠道的真实 ROI，一条补竞对情报。

不要写"加强 XX"这类没有验收标准的动作。

---

## 结论写作的三个硬要求

**1. 每个判断后面跟一个数。** 「达人直播成为增量主渠道」不够，要写「达人直播环比 +105.6%、占比 +7.0pp，是唯一翻倍的渠道」。

**2. 主动纠正自己上一版的结论。** 口径换了（比如从店铺层换到品牌层）导致结论变化时，明确说"上次说 X，改成 Y，原因是 Z"。不要悄悄改。

**3. 区分"结果"和"原因"。** 这份数据只有结果，看不出对手怎么做到的。所有归因都要标明是推断，并落到"需要补什么数据来验证"。

## 每周固定的待补数据清单

这份表只有结果数据。以下每周都要提，按优先级：

**P0（不补则第 4 步的结论站不住）**
1. 增长最快的对手，其主力渠道的供给结构：达人数量、Top3 达人贡献占比、是否有专场。1-2 个头部专场 = 一次性事件；30+ 达人铺开 = 可复制能力，威胁等级完全不同。
2. 逆势型对手把资源转去了哪里（需要它的分渠道明细）。
3. 我们与主要对手的达人重叠度。重叠高 = 在抢同一批人，报价会被抬高；重叠低 = 各有达人池，我们的池子深度是短板。

**P1**
4. KANS 自播的开播时长、场次、每小时 GMV。判断增长是效率提升还是堆时长——这是自播唯一有意义的效率指标。
5. KANS 主力渠道的佣金与坑位成本，算真实 ROI。GMV 涨了但 ROI 掉了要提前发现。
6. 一个不含大促的干净基线周，用来分离结构性趋势和大促脉冲。

**P2**
7. 商城（Shop Tab）流量来源拆分（搜索 / 会场 / 商品卡推荐）。商城占比长期是 KANS 短板，这是性价比最高的待验证抓手。

数据源对应：1-3 走 FastMoss / Kalodata；4-5 走 TikTok Shop 商家后台 + GMV MAX 报表；7 走 TTMS。
