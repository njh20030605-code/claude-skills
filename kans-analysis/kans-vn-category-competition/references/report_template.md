# 周报「市场竞争环境」正文模板

## 长度与配图

**目标：250–350 字 + 2 张图。** 这一节的读者要的是"我们的位置变了没有、下周动作要不要改"，不是越南市场谁排第几。不要写成竞品罗列。

配图固定两张：
- 图1（渠道结构 + KANS vs 大盘）配第一、二部分
- 图2（中国品牌梯队）或图6（品牌渠道占比）配第三部分

图3（异动散点）信息密度高，放附录或口头汇报时展开。

## 模板

```markdown
## 市场竞争环境（<日期区间>）

**一句话结论：<大促周/自然周>，大盘环比 <X>%，全行业增量主要由 <渠道> 承接。
KANS <跑赢/跑输>大盘 <N>pp、排名升至类目第 <R>，但 <一句限定——通常是"该动作是
行业共同动作，尚未形成差异化"或"增长依赖单一渠道，可持续性待验证">。**

### 一、大盘：增量渠道高度集中

| 渠道 | GMV 环比 | 占比变化 |
|---|---|---|
（五行，按环比降序，最高和最低两行加粗）

<一句话点出跑赢/跑输大盘最多的渠道>。Top200 入榜门槛从 A 抬到 B，榜单换手 N 家。

### 二、KANS 表现

- 品牌 GMV **<X> 万元，环比 <Y>%**，类目排名 **<A> → <B>**
- <渠道逐条，只列跑赢最多的两个和跑输的>
- 自播客单价 <A> → <B> 美元<持稳/变化>，增量来自<流量/客单>
- **短板：<渠道>，<数字>**（若二次校验后不成立就写"无系统性短板"）

### 三、竞争格局：三类打法分化

**跟随型**——<品牌+数字，2-3 个>。<一句话说明这是行业共同动作，我们处在什么位置>。

**逆势型（重点关注）**——<品牌+数字>。<一句话说明它为什么值得深挖>。其体量仍是 KANS 的 <N> 倍。

**空降型**——<品牌+数字，2-3 个>。<一句话说明这改变了竞价对手构成>。

### 四、下周动作

1. **提前打口径**：<本周排名上升的成因 + 下周大概率回落 + 下周主指标改成什么>
2. **验证 <主力渠道> 真实 ROI**：<该渠道已占多少 + 要核算什么>
3. **补齐竞对情报**：<优先拆解谁的什么打法 + 用来决定什么>

---
*数据口径：<数据源>类目导出，两周均在 Top200 的 <N> 家店铺为可比基准；多店铺品牌已合并至品牌层；汇率 1 USD = <rate> CNY。*
```

## 写法约定

- **结论先行**，每段第一句就是判断，后面才是支撑数字
- 不用 崩盘 / 崩塌 / 垃圾流量，用 差 / 下降 / 低质流量
- 不写口号式结尾、不写"让我们一起努力"这类话
- 国际大牌的极端增幅（+800% 之类）不进正文，放附录或口头说——它们和 KANS 不在同一价格带，写进正文会稀释重点
- 表格里的数字保留一位小数即可，占比用整数
- 提到"跑赢大盘 N pp"时，N = 品牌总GMV环比 − 大盘总GMV环比（不是五渠道合计口径）
