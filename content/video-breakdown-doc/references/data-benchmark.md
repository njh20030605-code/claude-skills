# 投放数据：取数口径、Benchmark、对外脱敏

## 取数（素材后台）

1. 用户的 Chrome（已登录素材后台）打开成片页，排序选「总消耗」（不是「今日消耗」或「总消耗（标准）」），主类目「全部」，不加日期筛选。
2. 逐条按**同一个时间段**取详情数据。
3. 列表数字只用来圈候选，不能直接当指标用。

## 口径坑（2026-10 实测）

- **列表「总消耗」≈ 2026-01-01 至今的累计**；只有 2025 年数据的素材，列表显示的是它 2025 年的总数。
- **2025 年的数据只有少数素材有**，很多老素材的数据从 2026-01-01 才开始；
  千川 3 秒完播、净成交也是 2026 年起才完整。所以统一口径只能用「2026-01-01 至 昨天」，不跨年。
- **重新上传的老素材**（同一天批量重传、ID 连号的一批）在列表里消耗被严重低估，
  会藏在 80 多名以后；按上传日期筛选不好用，直接按 ID 段逐个调接口查。
- 候选范围：列表前 120 名 + 可疑重传批次（标题日期是 2025 年、上传日期在 2026 年）。前 20 名的门槛按统一口径重算后再定。
- 个别素材详情页本身报「系统异常」、面板全 0，记下排名和列表消耗，在口径里注明「取不到、未纳入」。
- 详情页默认时间段是「上传日至今」，手动看数时一定改成统一时间段。

## Benchmark 怎么出

1. 前 20 条导出成 CSV：`name,spend,roi,netroi,ctr,cvr,s3,finish`（ctr/cvr/s3/finish 写百分数数值）。
2. `python3 scripts/svg_bench.py top20.csv out/ --title "韩束爆款数据 Benchmark" --sample "样本：……" [--tips tips.json]`
   → `bench.svg`（区间图）+ `stats.json`（P25/中位/P75/最值 + 与 ROI 的秩相关）。
3. N.1 里放：区间图、分级线表（冷启动看 3 秒完播和点击率的下四分位；A 档 ≈ P75 以上；B 档中位附近；C 档明显低于中位）、
   分类型/分产品表（点击率按素材类型比，转化率和客单按产品比）、20 条明细（按消耗排序，ROI 高标绿、低标红）。
4. 产品分组按**客单价**核一遍再用：标题里带「防晒」的可能是套装（客单 ≈ 套装价），不是单品。
5. 结论只写数据撑得住的：样本只有 20 条，「某类素材效率更高」至少要两条以上同类素材都在前 25% 才能写。

## 对外版脱敏（用户说「数据脱敏就行」时）

**原文档整篇复制一份，结构和文字一字不动，只改数据**，不要另起炉灶、不要加「能力概览」之类的新内容。

1. 整篇复制（命令见 doc-structure.md），文件名加「（脱敏版）」。
2. 在副本里找所有带数据的块：Benchmark 图、分级线、分组表、明细表、案例数据表、案例卡片里的数字、
   提到内部系统名（换成「素材后台」这类通用叫法）和素材 ID 的句子。用户手改过的措辞保留，只换数字。
3. 换算方式统一用**指数**（Top 20 中位数 = 100）：
   - 门槛：ROI 2.6 / 2.3 / 2.0 → 106 / 94 / 82（各自除以中位数）；冷启动线用 3 秒完播、点击率下四分位的指数。
   - 明细表：消耗换成排名，其他指标换成指数，标色规则同步改成指数。
   - Benchmark 图：`svg_bench.py --index` 重画；分组提示也写指数。
   - 案例数据表：改成「在 Top 20 中的位置」（前 25% / 中位数到 75% 分位之间 / 与中位数持平 / Top 20 最高 等）。
   - 金额、具体 ROI/转化率/完播率、退款率、客单价都不出现。
4. `python3 scripts/scan_sensitive.py <副本token> --profile personal` 复查；视频原话（「我拿出1万单」）、官方规则、举例价位可以保留。
5. 副本设公开，链接给用户。原文档公开与否听用户的。
