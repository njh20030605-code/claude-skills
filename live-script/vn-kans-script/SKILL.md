# VN KANS话术 —— 越南 KANS 直播间循环话术 + 手卡配牌

越南 TikTok 韩束(KANS)直播间的一轮循环话术工作流。核心不是"写一段好文案"，而是让**口播、主播动作、手卡视觉、平台履约**四件事在同一秒对得上——观众一边听一边看图，只要图上没有你念的东西，这一段就是掉信任而不是建信任。

---

## 一、先分清在做哪件事

用户的请求通常落在四类里，先判断，别一上来就写：

| 类型 | 典型说法 | 做什么 |
|---|---|---|
| A. 写新一轮话术 | 「写一版美白三件套的一轮话术」 | 按第二节框架从零搭 13 段 |
| B. 改现有话术 | 「把中控开场放到最后」「这段口播和卡对不上」 | **只改被点到的地方**，时间轴重算，其余一个字不动 |
| C. 手卡配牌 | 「这些手卡怎么放到对应话术旁边」 | 走第五节手卡工作流 |
| D. 从本地话术提取 | 「看看越南运营写的话术有什么能用的」 | 走第七节提取清单，输出建议不直接改框架 |

B 类最常见，也最容易做坏。用户交来的 xlsx 是他们团队在用的东西，**动得越少越好**。改完要明确告诉用户改了哪几处。

## 二、话术框架（基准版，不要重新发明）

一轮 **6 分 40 秒**，13 段，固定顺序：

| 时间 | 段落 | 优先级 |
|---|---|---|
| 0:00–0:40 | 拉新 + 挖痛点（**主播开场，全场第一句话**） | P1 |
| 0:40–1:20 | 三件套 + 核心差异化（假白反黑） | P0 |
| 1:20–1:45 | 成分（只讲一条线） | P2 |
| 1:45–2:25 | 功效对号入座（背诵级，每轮必念） | P0 |
| 2:25–2:40 | 主播自用（短版人设） | P2 |
| 2:40–3:30 | 价格公布 + 三步领券（全场核心转化点） | P0 |
| 3:30–3:55 | 赠品阶梯 · 第 1 次释放（洁面） | P1 |
| 3:55–4:15 | 赠品阶梯 · 拉扯（全场唯一一次） | P1 |
| 4:15–4:40 | 次抛「先试再留」（降门槛，专治犹豫） | P2 |
| 4:40–5:20 | 稀缺 + 轻演戏（全场唯一一次） | P1 |
| 5:20–6:00 | 倒计时收口 + 留住已买人群 | P0 |
| 6:00–6:40 | **中控硬广收口**（助播主口播，主播喝水/整理产品） | P0 |
| 6:40 | 主播直接接新一轮开场，回到 0:00 | P0 |

### 铁律：主播先开口，中控硬广收口

新人划进来最先看到的应该是**人和问题**，不是链接和价格。硬广放收口位还有个额外好处：「倒计时 → 硬广复述 → 主播新一轮钩子」形成双重收口，衔接下一轮不断档。

如果拿到的旧版本是硬广开场，主动提出把它移到最后，并把后面所有段落时间轴整体前移。总时长必须仍然是 6:40，加起来对不上就是算错了。

### 优先级机制：一版话术，三种节奏

话术只有一版。人多的时候不是换话术，是**按优先级砍模块**：

- **P0** 掉了这一轮就是无效轮：三件套差异化、功效对号入座、三步领券、倒计时、硬广 → 永远念
- **P1** 有转化增量但可压缩：痛点、赠品阶梯、稀缺演戏、已拍截图 → 峰值压缩或跳过
- **P2** 做认知和信任、转化贡献慢：成分、主播自用、次抛先试再留 → 峰值全跳

| | 峰值 | 常规 | 低峰 |
|---|---|---|---|
| 一轮时长 | 约 3'10" | 约 5'00" | 6'40" |
| 每小时轮次 | 18–19 轮 | 12 轮 | 9 轮 |

切峰值的触发条件（满足任一条，助播喊「切快节奏」，主播当轮立刻切）：在线人数比上轮翻倍以上；GMV Max 刚起量、曝光陡增；评论滚动快到读不完 ID；单轮进房 > 上轮 1.5 倍但成交没跟上。退出条件：在线回落到峰值 60% 以下，或连续两轮无成交。

峰值节奏下不要做三件事：不做赠品阶梯（一次报完）、不读长名单（只读 2–3 个 ID）、不讲成分和个人故事。人多的时候拉扯是浪费曝光。

**峰值极简版要单独写一份完整措辞**（约 3'10"），改写成更短更密的句子直接照念，不是简单删行。峰值版同样遵守「主播先开口、硬广收口」。

### 五种行类型（xlsx 里靠颜色区分，主播扫一眼就知道念不念）

| 角色 | 底色 | 字色 | 含义 |
|---|---|---|---|
| 主播 | 无 | `1A1A1A` 黑 | 主播口播 |
| 助播 | 无 | `1F6FB2` 蓝 | 助播/中控口播（含刷评论、报后台数据、配合演戏） |
| 手卡 | `FDF0ED` | `C0392B` 红 | 手卡/动作提示（举什么、看哪里、镜头怎么给）——主播念的时候不念这行 |
| 压缩 | `FFF6E0` | `8A5300` | 峰值时这段怎么砍，主播看这一行就够 |
| 红线 | `F2F2F2` | `6E6E6E` | 执行红线，主播不念，运营必看 |

段落标题行：底色 `2C3E50`，白色加粗，A:E 合并。优先级徽章：P0=`C0392B` / P1=`E9A13B` / P2=`9FB0BA`，白字居中。

## 三、产品与数字（默认值，每次用前跟用户核对一遍）

### ⚠️ 白系 vs 红系是最容易出错的地方

同一个品牌两个直播间，物料长得像，混用会直接讲错价格。判别信号：

| | 白系（本 skill 主要对象） | 红系 |
|---|---|---|
| 越南语 | `DƯỠNG TRẮNG` / `MỜ THÂM NÁM` / `LÀM TRẮNG` | `CHỐNG LÃO HOÁ` / `POLYPEPTIDE` |
| 中文 | 美白淡斑 | 抗老紧致 |
| 包装 | 白瓶 | 红瓶 |
| 三件套原价 | **1,427K** | **1,347K** |
| 核心成分 | 烟酰胺 99% / VC / 九肽-1 | 环六肽-9（Cyclo Hexapeptide-9） |

**看到 1.347K 就是红系的数字，不能出现在白系直播间。** 这个坑真实发生过：设计给的划价卡印的是 1.347K，白系必须改成 1.427K。

### 白系三件套（COMBO DƯỠNG TRẮNG MỜ THÂM NÁM）

- 美白爽肤水 300ml：**429K**
- 美白精华 30ml：**499K**
- 美白面霜 50g：**499K**
- 三件加起来原价：**1,427,000 越南盾**
- 直播专享价：**8XX K 起**（约 850K），领券后 6XX–7XX 都有人拿到，助播报自己账号优惠 17%
- **三件套里没有乳液（EMULSION）** —— 官方 5 步使用图含乳液，用在这个直播间会被问「乳液呢/是不是少发了」

### 赠品（走 TikTok Shop 后台绑定，跟单自动发）

- 氨基酸洁面 **50g 正装**（不是小样）
- **5 支次抛精华**，价值 **160K**
- 合计到手 5 件：三件正装 + 洁面 + 5 支次抛

赠品阶梯只做**一次**拉扯：先报洁面 → 让观众打「加赠」→ 再释放 5 支次抛。这样安全是因为释放的都是主图上本来就有的东西（延迟披露 ≠ 虚假承诺）。

### 成分：讲「四层抑黑」，不要讲 Ticracle Pro

除非确实有 Ticracle Pro 的手卡，否则不要念这个词——观众在图上找不到，本来最需要建信任的一段反而掉信任。改讲手卡上的四层抑黑，从表层到根源，主播手指从卡的上方往下走，一条停 2 秒：

1. **乙酰葡糖胺**（Acetyl Glucosamine）— 加快表层含黑色素的角质代谢脱落 →「这是你最先能看到的变化」
2. **维生素C**（Vitamin C）— 淡化已经形成的黑色素
3. **烟酰胺 99%**（Niacinamide 99%）— 拦住黑色素往皮肤表面跑
4. **九肽-1**（Nonapeptide-1）— 从源头抑制黑色素生成 →「最关键的一层」

收尾接卡顶的标题：「**14 天，让肌肤透亮起来，全面抑制黑色素。**它是让你的皮肤慢慢越来越亮、越来越均匀，不是一夜变白。这才是不会反黑、能长期用下去的美白。」

越南语必须**照抄卡面**，不要另译：
`14 NGÀY CHO DA SÁNG TRONG TRẺO` ｜ `ỨC CHẾ MELANIN TOÀN DIỆN` ｜ `Đẩy nhanh trắng bề mặt – Acetyl Glucosamine` ｜ `Mờ sắc tố đen – Vitamin C` ｜ `Giảm chuyển hoá – Niacinamide 99%` ｜ `Ức chế từ gốc – Nonapeptide-1`

如果一定要保留 Ticracle Pro，只在最后加一句当配方名（「这四个成分的配比就是 KANS 的专研配方 Ticracle Pro」），并且必须补做对应手卡。

### 其它可用证据

- SGS 用户实测：黑色素 −5.01%、肤色亮度 +7.67%、肤色均匀 +6.11%、泛红面积 −25.63%，14 天肤色均匀 / 4 周淡斑 → 专治「假白反黑」那句
- 中国官方机构美白淡斑认证 + SGS 敏感肌测试
- 品牌背书：抖音第一品牌、WWD 全球美妆 TOP 38、上海+日本双研发中心、20+ 年研发、200+ 项专利。⚠️越南话术里有「深耕 23 年」的说法，和卡上「20+ 年」口径不一致，**统一成卡面口径**，别让观众抓字眼
- 适用人群：18–60 岁、男女均可、干皮油皮混合皮均可

## 四、执行红线（写进 xlsx 的红线行，主播不念，运营必看）

这些不是合规套话，是真会变客诉和处罚的：

1. **赠品可以延迟披露，但不能超出主图。** 主图上有的可以先藏后放；主图上没有的（例：「我再给你加一瓶正装水」）系统不会发，直接变客诉。
2. **演戏的标的只能是「券名额 / 库存」**，这两个真实有上限，不会造成履约问题。不要拿赠品当演戏标的。
3. **不承诺具体天数的效果。** 「14 天透亮」这类只能引用手卡上已有的官方文案，不要主播自己加天数。
4. **不用极限词**，不承诺平台不提供的保障。
5. **「前 10 单恢复原价」这类话必须真执行**，后台不会真改价就不要说，继续用「券名额不到十份」更安全。
6. **同一场内同一场戏不重复**（稀缺演戏全场一次、赠品拉扯全场一次）。重复第二次观众就不信了，而且拉低整场节奏。

## 五、手卡工作流

### 第 1 步：分系归类

物料 PDF 往往把两个直播间混在一起。先逐页看图，按第三节的判别信号分成白系 / 红系，**红系全部剔除**，并明确告诉用户剔了多少张、为什么。两个直播间的牌不要混放在同一个牌架上。

技术上：用 `pypdfium2` 把物料 PDF 每页渲染成 PNG（`scale=2.0~2.6`），拼一张 contact sheet 一次看完，再逐张确认可疑的。

### 第 2 步：编号

按使用频次和用途分三组，编号本身要能表达「举不举」：

- **主 A 组** = 每轮固定举（约 5–7 张）
- **备 B 组** = 按弹幕触发补（约 6–7 张）
- **中 C 组** = 品牌背书，任意位置可插（1–2 张）

文件名格式：`主A1_三件套主图_水+精华+霜_买3送2.png`，编号在前，用 `_` 分段，方便脚本按前缀取。

### 第 3 步：逐段配牌

配牌的判断标准不是「这张卡好看」，而是**这一段口播的那个具体句子，观众需要看到什么才能相信**。参考映射：

| 段落 | 手卡 | 举牌指令要点 |
|---|---|---|
| 拉新挖痛点 | 主A2 痛点卡 | 前 15 秒空手看镜头，念到「我再问细一点」才举，念一条指一条 |
| 三件套差异化 | 实物 → 主A3 SGS 实验 | 三件套按 水→精华→霜 各停 3 秒；讲完「不是假白反黑」立刻切 SGS 卡指数字停 5 秒 |
| 成分 | 备B1 四层抑黑 | 手指从卡上方往下走，一条停 2 秒，最后指卡顶的「14 NGÀY」 |
| 功效对号入座 | 主A2 → 主A4 官方认证 | 痛点卡重新举高，念到「过了 SGS 敏感肌测试」切认证卡停 3 秒 |
| 主播自用 | 不举卡 | 用手指自己的脸，镜头拉近 |
| 价格公布 | 主A7 划价卡 → 主A1 主图 | 手掌先盖住数字，念到「三样加起来」拉开停 3 秒，报完原价立刻换主图报直播价。**落差感靠两张卡切换，只举主图会弱一半** |
| 读评论到手价 | 不举卡 | 全部放下，眼睛盯评论区，必须真实念出观众的数字和名字 |
| 赠品洁面 | 洁面实物 | 只举这一件，次抛先藏起来不出镜 |
| 赠品拉扯 | 次抛实物 | 打「加赠」的人够多了才拿出来，举高停 5 秒 |
| 次抛先试再留 | 实物 →（备B3 单品精华） | 挤一点在手背给镜头看质地；有人说「只想买精华」才补 备B3 |
| 稀缺演戏 | 不举卡 | 转头看后台屏幕，做出真的在看数据的动作 |
| 倒计时收口 | 主A5 下单引导 → 主A6 使用步骤图 | 先指「券领了/到手价对不对/赠品在不在购物车」，再举步骤图倒数让观众截图 |
| 中控硬广收口 | 主A1 主图 | 举到镜头正中，本段全程不放下 |

同一张卡在一轮里出现 2–3 次是**好事**，不是偷懒——换牌越少主播越不容易乱，观众也更记得住。

### 第 4 步：缺卡诊断（这一步最有价值）

逐段问：这段口播提到的东西，有没有对应视觉？没有就是缺卡。按影响转化的程度排 P1/P2/P3，每条写清「为什么要做 + 卡面要写什么」。常见的缺口：

- **价格阶梯卡**（原价 → 直播价的落差）——价格段是全场核心转化点，只有主图撑不住
- **使用步骤图**——收口让观众截图保存的道具，直接影响退款率
- **正品保障 + 售后保障卡**——官方旗舰店蓝标 / 扫码验真 / 正规发票 / 平台退换货 / 每天直播答疑。越南市场对假货高度敏感，这块常常裸讲
- **0 元赠礼互动卡**（QUÀ 0 ĐỒNG）——点赞 / 分享 / 评论区打「年轻」，比纯口播「打1打2」多一个实物钩子
- **赠品清单卡**——洁面 50g 正装 + 5 支次抛（价值 160K），观众得看清送什么、值多少

已有卡但**数字或步数不对**的，单独标成「需改卡」而不是「缺卡」——改一个数字比重做一张便宜得多，要让用户看清区别。

## 六、越南本地化

### 翻译规则

xlsx 留一列 `Tiếng Việt（本地翻译填写）` 给本地团队。凡是手卡上已有的越南语文案，**必须逐字照抄卡面**，不要重新翻译——观众是对着图听的，用词不一致就对不上。

### 越南市场特有的顾虑（中国话术里常常没有，值得加）

- **怕含激素、违规添加**：「想美白，但又担心用了含激素、违规添加的产品反而伤害皮肤」。这条能直接接官方认证卡，形成「痛点 → 背书」闭环
- **怕买到假货**：官方旗舰店 100% 正品 / 每件扫码验真 / 正规发票来源可追溯
- **怕买错不会用**：平台符合条件可退换；KANS 每天直播，收到不会用可以回直播间问

### 从本地运营话术里提取增补点

越南运营自己写的话术（通常是 CSV/表格，分 开场 / TĂNG CTR / TĂNG CTOR / CTA 四大板块）里常有中国框架没有的东西。**提取，但不要用他们的结构替换框架**——框架的时间轴和优先级是调过的。逐条评估：

| 值得拿 | 为什么 |
|---|---|
| 0 元赠礼互动小游戏 | 有实物钩子，评论量和停留比「打1打2」高一档 |
| 正品保障三件套 | 加在硬广里几乎不占时间，直接压「怕假货」 |
| 售后保障 | 压「怕买错、怕不会用」，对退款率有用 |
| 赠品价值锚定 160K | 把赠品从「附送」变成能算的钱 |
| 「加赠」互动词 | 比「打2」语义明确，也利于后台识别高意向 |
| 已加购未下单人群单独喊 | 全场离成交最近的一批人，框架里常常漏掉 |

| 要小心 | 为什么 |
|---|---|
| 「深耕 23 年」 | 和手卡「20+ 年」口径冲突，先对齐再用 |
| 「前 10 单恢复原价」 | 必须真执行，否则是虚假宣传 |

输出成一个单独的 sheet，每条写「可提取的点 / 建议插到哪一段 / 现成措辞 / 为什么值得加 / 结论」，让用户自己挑，不要替他决定。

## 七、输出物规范

### 话术 xlsx（主交付物）

sheet 结构：

1. `0.说明与节奏` — 颜色与角色图例、优先级机制表、什么时候切峰值、改版说明
2. `1.机制卡与红线` — 锚点类型、执行红线
3. `2.主话术（基准6分40秒）` — 列：`优先级 | 角色 | 内容（中文）| 手卡 | Tiếng Việt（本地翻译填写）`
4. `3.峰值极简版（3分10秒）` — 列：`角色 | 内容（中文）| Tiếng Việt | 手卡`
5. `4.附录-国内越南移植对照`
6. `5.附录-原稿处理清单`
7. `6.手卡库` — 编号 / 手卡图 / 卡面内容 / 原始物料页码 / 用在哪一段 / 状态 / 举牌指令，底部接缺卡清单
8. `7.从本地话术可提取的增补点`（有本地话术时才加）

### 手卡手册 PDF（给现场打印）

- 封面：这份卡怎么来的（剔了哪些）+ 逐段举牌表 + 主/备/中分组说明
- 第 2 页：定制卡需求清单，按 P1/P2/P3 排

## 八、技术要点（这些坑踩过，别再踩）

处理 xlsx 用 `openpyxl`，物料 PDF 用 `pypdfium2` 渲染，图片处理用 `PIL`。

1. **openpyxl 无法删除已插入的图片。** 要换手卡列的图，只能整张 sheet 重建：先把每个 cell 的 `value` + `copy.copy(font/fill/alignment/border)` + `row_dimensions[r].height` + 合并区域 + 列宽全部快照，写到新 sheet，再 `del wb[old]` 并 `move_sheet` 回原位。重排段落顺序也用同一套方法（按段落行区间搬块）。

2. **WPS 的 `=_xlfn.DISPIMG(...)` 嵌入图公式在 openpyxl 里会失效。** 遇到就清掉，换成「文本标签 + 真正的 XLImage」。

3. **`reportlab` 不能用 Noto Sans CJK**——`.ttc` 是 PostScript/CFF 轮廓，会报 `postscript outlines are not supported`；转 glyf 要 cu2qu 一路踩坑，不值得。**改用 PIL 排版成 A4 位图页，再用 `img2pdf` 合成**，中文和越南语变音符号都正常。字体走 `ImageFont.truetype('/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc', size, index=2)`（index=2 是 SC）。
   注意 PIL 的 PDF 保存可能缺 JPEG 插件（`KeyError: 'JPEG'`），所以走 `img2pdf`：先把每页存成 JPEG（quality 88），再 `img2pdf.convert(paths, layout_fun=get_layout_fun((mm_to_pt(210), mm_to_pt(297))))`。

4. **行高换算**：Excel 行高单位是 pt，图片是 px，`行高 pt = 图片px高 × 0.75 + 边距`（有文字标签留 22–40，没有留 8）。手卡缩略图宽度 190–240px 配 D 列宽 30–36 比较合适。

5. **手卡缩略图**先统一缩到 300px 宽存一份，xlsx 和 PDF 都从缩略图取——原图直出会让 xlsx 涨到几十 MB。

6. **段落重排后一定验算总时长**。13 段时长相加必须等于 400 秒（6'40"）。

7. **交付前用 `soffice --headless --convert-to pdf` 渲染一遍**粗看有没有炸版。LibreOffice 会把列拆到不同页，所以看图是否落在正确行要靠 `openpyxl` 复查 `_images` 的 anchor，不要只看渲染图。

## 九、沟通习惯

- 改完先说**改了哪几处**，再说为什么，不要复述整份文件
- 发现数字/口径冲突（1.347K vs 1.427K、23年 vs 20+年、5步含乳液）要主动指出并说清影响，这类问题用户自己很难发现
- 缺卡和需改卡分开讲，改一个数字和重做一张卡的成本差很多
- 交付 xlsx + PDF 之后不要长篇解释文件内容，用户会自己看
